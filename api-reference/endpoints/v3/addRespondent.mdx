<Note>
The **Duplicate Entrance Score (DES)** is available on **v3 only**. Include at most one DES datapoint with `entranceTime`, optional `ip`, and up to 10 demographics (at least 4 for a valid score). See the [Duplicate Entrance Score](/knowledge-base/quality-checks/duplicate-entrance-score) knowledge base page for scoring details.
</Note>
