---
title: 'Credit Calculation'
openapi: 'POST /creditCalculation'
---

If you need to estimate the number of credits required to add a respondent, you can use this endpoint.

<Note>This endpoint is optional and serves informational purposes only. It provides an estimate of the credits required based on the selected quality scores.</Note>

`DESDataPoints` is optional and defaults to `0` if omitted.

Send exactly one of `GQSDataPoints` or `GQSAnswers`. `GQSDataPoints` is the GQS data-point count. `GQSAnswers` is the legacy item count and is converted with `floor(GQSAnswers / 5)` before pricing. Sending both returns 400.
